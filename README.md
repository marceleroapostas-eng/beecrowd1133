# Beecrowd 1133 - Resto da Divisão

## Descrição
Programa desenvolvido em Java para identificar e imprimir os números de um intervalo cujo resto da divisão por 5 seja igual a 2 ou 3.

## Linguagem
Java

## Entrada
O programa recebe dois números inteiros positivos X e Y, que definem os limites do intervalo.

## Saída
Imprime os números que atendem à condição, em ordem crescente.
